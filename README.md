# Prerequisites

Note that the prerequisites of `bevy` need to be satisfied. You can find them
in the [`bevy` docs](https://bevy.org/learn/quick-start/getting-started/setup/#installing-os-dependencies) e.g. [for Linux](https://github.com/bevyengine/bevy/blob/main/docs/linux_dependencies.md).

# To build:

## Cargo:

With `cargo` installed, you can simply run:
```
cargo run
```
which will both build and then run the game.
